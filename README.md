# NeverExpire

## 📌 Overview
NeverExpire is an AI-powered document management application that helps users track expiry dates of important documents such as passports, IDs, certifications, and licenses.

The system automatically extracts key information from uploaded documents and sends timely reminders before expiry.

---

## 🎯 Objectives
- Eliminate missed expiry dates
- Automate document classification
- Provide proactive renewal reminders
- Support family member document tracking

---

## 🧠 Key Features
- 📷 Document upload (image/PDF)
- 🤖 AI-based OCR extraction
- 📅 Expiry date detection
- 🔔 Smart reminder system
- 👨‍👩‍👧 Multi-user / family support
- 📂 Document categorization
