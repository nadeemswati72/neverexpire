HT-402 Today strip

Horizontal cards sorted by next-due time. Tap = check-in (haptic + tick). Interval habits (💧) show windows-hit progress. Completed cards sink right with ✓ and fade. Auto-tracked completions (🚶) show their source — "auto · 8,412 steps".

HT-403 Streak hero

The single most motivating number: best active streak with a growing flame, best-ever record, and remaining streak freezes. Growth stages and freeze mechanics in 07-visual-streaks.html.

HT-404 Consistency heatmap

35-day GitHub-style grid, 5 intensity levels of overall completion. Frozen days render in cyan — honesty over illusion. Vacation days show hollow. Tap a cell → that day's detail.

HT-405 Category rings

Per-category completion with day/week/month toggle. The 14-day rolling rate drives labels: thriving ≥80%, wobbling 50–79%, needs help <50% — always supportive wording, never shaming. This feeds the AI coach's targeting in Phase 2.

HT-401 Weekly bars + one API call

Everything on this screen comes from GET /habits/dashboard — a single aggregate response (<500ms budget). Mobile renders; the backend computes. Streak rules never re-implemented client-side.

HT-406 Insight card

Exactly one observation, rotating: best time-of-day, weekday pattern, perfect days. Rule-based in Phase 1; AI-written (stats-grounded) from Phase 2. Dismissible.

HT-502 Quote card

Tag-matched to category + moment. Global off-toggle honored everywhere. Never shown on medication surfaces.
