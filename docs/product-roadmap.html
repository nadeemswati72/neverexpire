Overview

What is NeverExpire?

NeverExpire is a smart document management platform that tracks expiry dates for passports, visas, driving licences, Emirates IDs, insurance policies, and any other time-sensitive document — for every member of a family or business team. The AI reads your documents automatically so there is almost no manual data entry.

Current Release

What Is Built & Working Today

Sprints 0 through 5 are complete. The full web application is live on the backend. The mobile app is built and in device testing on the sprint5-mobile branch.

🤖 AI Document Extraction — Core Differentiator

Users take a photo or upload a PDF of any document. Claude AI reads the document automatically and extracts: title, document number, issuing authority, holder name, issue date, and expiry date — with a confidence score. The user reviews the extracted fields, corrects anything if needed, and saves. This eliminates almost all manual data entry. The feature works on both web and mobile (camera or gallery). Supported formats: JPG, PNG, WebP, PDF.

🔐 Authentication & Security

🔑

Email + Password Login

Secure registration and login with email and password. Passwords hashed with bcrypt. Minimum 8 characters enforced.

🎟️

JWT Session Tokens

All API requests use Bearer token authentication. Tokens expire automatically. Auto-logout on expiry on both web and mobile.

🛡️

Cross-User Data Protection

Every endpoint verifies ownership. User A cannot access, view, or modify User B's documents, family members, or files — enforced at the API layer.

💧

Watermarked File Serving

Every uploaded document image is automatically watermarked with a tiled pattern before being stored. Documents served only to the owner via authenticated requests.

Future Vision

Horizon Features

Creative extensions that transform NeverExpire from a document tracker into an indispensable life management platform. These are discussed and recorded — timelines and prioritisation to be decided.

Future Release 01

✈️ Travel Readiness Check

Planning a family trip? NeverExpire checks all family members' passports, visas, vaccination cards, and travel insurance against the destination country's requirements. Shows a clear "Ready to Travel" or "Action Needed" status per person. Highlights passport validity gaps — most countries require 6 months remaining validity.

🇦🇪 UAE-specific: UAE expats travel 3–5 times per year internationally. This feature is uniquely relevant to the market.
Future Release 02

💬 WhatsApp Reminder Bot

Reminders delivered via WhatsApp Business API. "Your Emirates ID expires in 30 days. Tap to see renewal steps." Users reply to snooze, dismiss, or get the full guide. WhatsApp has 95%+ penetration in the UAE and achieves far higher open rates than push notifications or email.

🇦🇪 UAE differentiator: No other document management app in the region offers WhatsApp-native reminders.
Future Release 03

🏠 Household Staff Module

Dedicated management for maids, drivers, nannies, and gardeners. Each staff member needs an employment visa, health card, medical fitness certificate, and labour card tracked separately. Bulk tracking and group notifications alert the employer when any staff member's document is expiring. Premium plan feature.

📝 Already possible today: Add staff as "Other" family members and track documents normally. This sprint formalises it with bulk tools and employer-specific alerts.
Future Release 04

🚗 Vehicle Health Tracker

UAE-specific: Mulkiya (car registration), RTA vehicle inspection certificate, car insurance, Salik toll tag balance alerts, and car service interval reminders (every 10,000 km or 6 months). The existing AI extraction pipeline can already read a Mulkiya card — this sprint builds the vehicle category around it.

📝 Already possible today: Vehicles can be tracked manually by creating a document entry with the relevant expiry dates.
Future Release 05

🤖 Smart Renewal Guide

When a document is 60 days from expiry, NeverExpire generates a step-by-step renewal guide. "Your UAE Residence Visa expires in 45 days. Steps: 1. Book GDRFA appointment, 2. Prepare these 6 documents, 3. Fee: AED 2,800, 4. Processing time: 5 working days." AI-generated, specific to document type and nationality. Turns NeverExpire from a passive tracker into an active action platform.

Future Release 06

🆘 Emergency Document Access

Designate a trusted emergency contact — a spouse, parent, or sibling. If the account holder is hospitalised or unreachable, the designated contact receives a one-time 4-hour access code to view critical documents: passport number, insurance policy, emergency contact, blood type card. Fully audited, time-limited, and no permanent access granted.

Future Release 07

📵 Offline Document Wallet

Download encrypted copies of selected documents to your phone. No internet required to view. Unlock with Face ID or fingerprint. Critical for border crossings, hospital visits, and areas with poor connectivity. Documents are AES-encrypted on the device. When you get signal, the wallet syncs and updates automatically.

Future Release 08

🏠 Property & Lease Tracker

Track EJARI (UAE tenancy contract registration), building service charge schedule, maintenance contracts, utility deposit receipts, and mortgage paperwork. UAE expats move every 2–3 years — EJARI renewal is mandatory and a common missed deadline. AI reads the lease document and extracts dates automatically.

📝 Already possible today: Properties and leases can be tracked manually as document entries.
Future Release 09

🎒 Children's School Document Hub

Each academic year, schools require: vaccination records, health insurance card, passport copy, birth certificate, medical fitness form, and emergency contact form. NeverExpire alerts parents in July and August — weeks before school registration — with a checklist of what is missing or expired for each child. Eliminates last-minute scrambles before the school year.

Future Release 10

🎬 Subscription & Warranty Wallet

Extend beyond government documents: gym membership, streaming services (Netflix, Spotify), software licences, car warranty, home appliance warranties (AC, refrigerator), building maintenance contracts. Same expiry pattern — different everyday use case. Makes NeverExpire genuinely useful for users without complex document portfolios, dramatically broadening the market.

📝 Already possible today: Subscriptions and warranties can be tracked manually as document entries without uploading a file.
Future Release 11

🌐 Arabic Language Support

Full right-to-left (RTL) interface in Arabic. UAE government documents are bilingual — the AI extraction already sees Arabic text. An Arabic interface unlocks a major user segment in the UAE, Saudi Arabia, and wider GCC market that current competitors entirely ignore. Includes translated UI, Arabic field labels, and RTL layout across web and mobile.

🇦🇪 GCC market: Arabic is the first language for a significant share of UAE residents and the primary language in all neighbouring markets.
Future Release 12

☁️ SaaS Business Tier

Multi-tenant architecture with subscription billing. Businesses pay per seat (e.g. AED 15/employee/month). HR managers get a company dashboard. API access for enterprise integrations with HRMS and payroll systems. White-label option for PRO typing centres, legal firms, and PRO service companies to offer NeverExpire as their own branded product.

💼 Revenue model: Business SaaS subscriptions, white-label licensing, and premium feature tiers.
Technical

Architecture at a Glance

Built for reliability and scale from the first day. Ready to migrate from SQLite to PostgreSQL and from Railway to any cloud provider without architectural changes.

⚙️

Backend — Flask REST API

Python Flask with SQLAlchemy ORM. Pure REST — no server-side rendering. JWT authentication. SQLite for development, PostgreSQL-ready for production. Deployed on Railway.

🌐

Web — React + Vite

TypeScript React application. Tailwind CSS with glassmorphic design system. Axios API client with automatic JWT injection. Vite for fast builds and development.

📱

Mobile — React Native (Expo)

Managed Expo SDK 54 workflow. No native build configuration needed. React Navigation v6. Compatible with Expo Go for testing. iOS + Android from a single codebase.

🤖

AI — Anthropic Claude

Claude AI reads document photos and PDFs to extract structured data. Configurable model (currently claude-sonnet-4-6). Confidence scoring returned with every extraction.

🖼️

File Processing — Pillow

Automatic watermarking of all uploaded document images. Tiled pattern applied server-side. File ownership verified before serving. Avatars resized to 200×200 automatically.

🔒

Security

Ownership-checked endpoints (cross-user access denied). bcrypt password hashing. JWT tokens with configurable expiry. CORS configured for web and mobile clients.
