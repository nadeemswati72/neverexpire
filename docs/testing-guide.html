Before You Start

  • Big change from last round: the website and the mobile app now use the same accounts and the same data. A document you add on your phone appears on the website, and vice versa.
  • Every demo account uses the same password: Demo@1234
  • To use the mobile app (including AI document scan), your phone must be on the same Wi-Fi network as the developer's computer.
  • On a different network? Review the screen walkthrough below and send feedback on layout and wording instead.

1. Testing the Website

Open the address the developer gives you, e.g. http://<developer's IP>:5173.

  • Dashboard — stat cards, status donut chart, and the family sidebar. Click a family member: every card, chart, and list narrows to them.
  • Documents — add via AI photo/PDF upload (review before saving), add manually (with optional picture), edit, delete, filter by status. Shared documents carry a badge.
  • Sharing
    • Open a document → share it by email with a permission level (view / view+download / edit) and an optional expiry (7 or 30 days).
    • Family page → member menu → Share All Documents (optionally including future ones).
    • Sharing page — incoming/outgoing shares, revoke access.
    • As the owner, watch Access History update when the recipient views/downloads.
    • Downloads by recipients carry a personalized watermark naming them.
  • Notifications — bell icon shows share/revoke events with unread badges.
  • Mock Inbox — demo view of the emails the system would send.
  • Family — members with photos, add member (incl. Domestic Help relation).

2. Testing the Mobile App

Set up: install Expo Go (App Store / Play Store), join the developer's Wi-Fi, then scan the QR code the developer shares. First load compiles the app and can take a minute.

What to Test

  • Login / Register — tap a demo account to autofill, or create a fresh account. new
  • Dashboard — summary cards, status donut chart new, and family member filter chips new that narrow everything to one person.
  • Add Document — camera / gallery / file, AI pre-fills the form; review and save. Or enter manually.
  • Document Details — full watermarked picture new, details, edit, delete.
  • Share a document new — Details → Share, enter another demo email, pick permission + expiry. Log in as the recipient (or check the website) to confirm.
  • Sharing screen new — drawer → Sharing: "Shared with Me" / "Shared by Me", revoke outgoing shares.
  • Access History new — on your own shared document, see who viewed/downloaded it.
  • Family — member photos new, add member with relationship picker, and the share icon to share ALL of a member's documents. new
  • Member documents — per-member status donut new + document list.
  • My Documents — search + status filter chips.
  • Notifications — sharing activity (unread dots, mark all read) new + expiry reminders; the dashboard bell shows a live badge.

Known Limitations

  • Share emails are mocked — view them in the website's Mock Inbox. Recipients get in-app notifications.
  • Change Password and the Settings toggles are UI-only this round.
  • Camera capture needs a real device.
  • Daily reminder digest emails go to the developer's Gmail during the PoC.
