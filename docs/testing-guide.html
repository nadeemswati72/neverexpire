Before You Start

  • Web, iOS, and Android all use the same accounts and the same data — a document you add on your phone appears on the website, and vice versa.
  • Every demo account uses the same password: Demo@1234
  • Web is a public URL — test it from anywhere, anytime.
  • iOS and Android (Expo Go) need your phone on the same Wi-Fi network as the developer's computer, which must be running the backend + Metro bundler during your test session.
  • If you find a bug, don't fix your test data around it — note it (see Reporting Issues) and keep going. Untidy demo data helps prove things actually work.

Setup — Android

Same idea as iOS, different app store. The mobile app is one shared React Native codebase — nothing Android-specific to install beyond Expo Go itself.
Never tested on real Android hardware before this round. Every fix in this round was verified through a browser-based React Native preview (no iOS/Android-specific code paths were touched), but this is genuinely the first pass on an actual Android device or emulator. Please pay extra attention to anything Android-specific: back-button behavior, camera/gallery permission prompts, keyboard covering input fields, and the system status bar/nav bar overlapping content.

Reporting Issues

For each issue, please note:

  • Which platform (Web / iOS / Android) and which account you were on
  • The screen and the exact action you took
  • What you expected vs. what actually happened
  • A screenshot or screen recording if you can — it helps enormously
